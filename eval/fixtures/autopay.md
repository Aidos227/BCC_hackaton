# Автопополнение мобильной связи

## Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Автопополнение баланса телефона с карты |
| **Продукт** | Мобильный банк |
| **Влияние на ИС** | Мобильный банк, сервис платежей, шлюз операторов связи, сервис уведомлений |

## Цели
Клиенту не нужно следить за балансом телефона: банк пополняет его автоматически.

## Функциональные требования
* **АП-1.** Клиент подключает автопополнение для одного номера телефона и одной своей карты KZT.
* **АП-2.** Клиент задаёт сумму пополнения от 100 до 20 000 ₸ целым числом и порог баланса от 0 до 5 000 ₸.
* **АП-3.** Когда оператор сообщает, что баланс номера стал ниже порога, банк списывает сумму пополнения с карты и переводит её оператору.
* **АП-4.** Автопополнение выполняется не чаще одного раза в сутки.
* **АП-5.** После успешного пополнения клиент получает push с номером карты, номером телефона и суммой.
* **АП-6.** Клиент может отключить автопополнение в любой момент; отключение действует сразу.

## Нефункциональные требования
* **НФ-1.** Уведомление о пополнении должно приходить клиенту быстро.
* **НФ-2.** Сервис обрабатывает событие оператора не дольше 30 секунд с момента получения.

## Требования к данным
Хранить номер телефона, идентификатор карты, сумму пополнения в тиынах, порог баланса в тенге, дату последнего пополнения.

## Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Порог 500 ₸, сумма 1 000 ₸ | Оператор сообщает баланс 499 ₸ | Списано 1 000 ₸, push отправлен |
| Порог 500 ₸, сумма 1 000 ₸ | Оператор сообщает баланс 500 ₸ | Списано 1 000 ₸, push отправлен |
| Пополнение уже было сегодня в 09:00 | Оператор сообщает низкий баланс в 21:00 | Списания нет |

## API «Сохранить настройки автопополнения»

| Поле | Значение |
| :--- | :--- |
| **REST type** | POST |
| **URL** | `/autopay/settings` |

### Параметры запроса

| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `phone` | string | Да | +7XXXXXXXXXX | Номер телефона |
| `cardId` | string | Да | Карта клиента | Идентификатор карты |
| `amount` | integer | Да | 100–50 000 | Сумма пополнения в тенге |
| `threshold` | integer | Да | 0–5 000 | Порог баланса в тенге |

### Ответы
* **200** — настройки сохранены: `{"result":"OK"}`.
* **400** — параметры заполнены неверно: `{"message":"Некорректные параметры"}`.
* **401** — нет авторизации.
